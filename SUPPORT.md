# WebCode support policy

## Getting help

For usage questions, open a [Question or support issue](https://github.com/Louis2324/WebCode/issues/new?template=question.yml). For reproducible defects, use the bug report form. Search existing issues first and include the WebCode version, operating system, architecture, steps to reproduce, and relevant logs with secrets removed.

## Supported versions

The latest published release and the active `main` branch receive normal maintenance. Release candidates are test builds and may contain known limitations. Older releases are supported on a best-effort basis only.

## What support cannot promise

WebCode is an early-stage project. We cannot currently promise support for every Linux distribution, very large projects, third-party extensions, or workflows that depend on a backend server.

Security vulnerabilities must be reported privately using [SECURITY.md](SECURITY.md), not through a public issue.
