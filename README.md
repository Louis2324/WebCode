# WebCode

[![CI](https://github.com/Louis2324/WebCode/actions/workflows/ci.yml/badge.svg)](https://github.com/Louis2324/WebCode/actions/workflows/ci.yml)
[![Latest release](https://img.shields.io/github/v/release/Louis2324/WebCode?display_name=tag)](https://github.com/Louis2324/WebCode/releases)

WebCode is an offline Electron code editor for learning and building small web applications with HTML, CSS, and JavaScript.

The project is intentionally focused: write code, preview it safely, run simple validation tests, save a project, and learn through an approachable desktop workflow.

## Status

WebCode is under active development. The repository has automated validation and cross-platform installer builds, but release artifacts are currently unsigned. Use the latest GitHub release for packaged builds and `main` for the current development version.

## Features

- HTML, CSS, and JavaScript editors powered by Ace.
- Sandboxed live preview.
- Simple JavaScript validation tests.
- Local project save and load as JSON.
- `Ctrl+Enter` / `Cmd+Enter` to run code.
- `Ctrl+S` / `Cmd+S` to save a project.
- Desktop preview window.
- Offline desktop assets; no runtime CDN dependency.
- Windows NSIS installer, macOS DMG, Linux AppImage, and Linux `.deb` build targets.

## Downloads

Download the latest installer from the [Releases page](https://github.com/Louis2324/WebCode/releases).

The Windows NSIS installer registers WebCode with Windows and includes the normal uninstall entry. The uninstaller is generated by Electron Builder as part of the Windows installation; it is not a separate manually maintained application.

Release artifacts are currently unsigned. Windows SmartScreen or macOS Gatekeeper may show a warning until code signing and notarization are configured.

## Development

Requirements:

- Git
- Node.js 22 or a compatible current LTS release
- npm

```bash
git clone https://github.com/Louis2324/WebCode.git
cd WebCode
npm ci
npm start
```

For live development:

```bash
npm run dev
```

Build a local installer for the current platform:

```bash
npm run package
```

Run the repository checks:

```bash
node --check main.js
node --check preload.js
node --check menu.js
node --check dist/script.js
npm test
```

## Automated builds and releases

GitHub Actions validates every pull request and every push to `main`. The CI workflow installs dependencies, validates package metadata, checks JavaScript syntax, runs tests when available, and builds an unpacked Electron bundle.

The release workflow runs only for version tags matching `v*.*.*`. Before building, it verifies that the tag matches `package.json`. It then builds these artifacts in parallel:

- Windows x64 and ARM64 NSIS installers.
- macOS x64 and ARM64 DMG and ZIP packages.
- Linux x64 and ARM64 AppImage and `.deb` packages.

The workflow collects the artifacts, generates `SHA256SUMS.txt`, and publishes a GitHub Release with generated notes. Signing and notarization are intentionally disabled until the required repository secrets and certificates are configured.
